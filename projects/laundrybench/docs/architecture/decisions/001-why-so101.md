# ADR 001 — Use SO-101 for V1

## Decision
Use an SO-101 leader/follower setup as the first physical platform.

## Why
- low cost relative to larger robots
- supported by the LeRobot ecosystem
- supports real demonstration collection and manipulation evaluation
- simple enough that hardware does not dominate the project
- extensible toward richer manipulation tasks

## Tradeoff
The single-arm workspace limits task reach and payload. Validate the data, policy,
and evaluation workflow before adding hardware complexity.

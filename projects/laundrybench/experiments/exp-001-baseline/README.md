# EXP-001 — Baseline

**Date:** 2026-09-15
**Status:** Planned
**Hardware:** physical
**Owner:** James Wang

## Question

How reliably can the first working policy sort one sock from one non-sock item under fixed conditions?

## Hypothesis

A narrow, controlled setup should produce a measurable baseline that is stable enough for later comparisons.

## Evaluation protocol

- fixed table and camera
- fixed basket locations
- one sock + one non-sock item
- no overlapping garments
- manual reset between attempts
- record success/failure, completion time, intervention, failure category

| LaundryBench | Laundry manipulation benchmark and evaluation workbench for an SO-101 arm | [Overview](laundrybench/README.md) |

Each project owns its runtime, dependencies, configuration, tests, operating guides,
and experiment records. Keep project-specific code within its directory. Introduce
a shared package only when a second project has a concrete need for the interface.

A project should document its task, hardware assumptions, reproducible commands,
evaluation protocol, current evidence, and known limitations before reporting results.

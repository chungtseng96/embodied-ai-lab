# Kinematics

Kinematics connects joint motion to end-effector motion.

## Forward kinematics

Given the joint values, determine where the gripper is.

```text
joint values -> end-effector pose
```

## Inverse kinematics

Given a desired gripper pose, determine joint values that can reach it.

```text
desired end-effector pose -> joint values
```

For this project, the goal is conceptual fluency and practical debugging—not deriving the math by hand.
